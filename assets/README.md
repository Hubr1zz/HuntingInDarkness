## 第三章（美术）：墨线速写概念稿

美术章节里的图（`A-01` ~ `A-04`、`C-01`、`Z-01` ~ `Z-03`）统一画成墨线加软边平涂色块的速写稿，像设计师速写本里的一页，而不是成品插画。只用这一种画法；首屏、序章、玩法等其他图仍按成品插画规范。画法以已定稿的 `C-01` 为准，生图用 kdm生图 工作流里的 `ink-flat-white` / `ink-flat-tan` 风格块。

- **墨线**：手绘的黑色墨线，下笔肯定、略带抖动，随力度变粗变细，转角偶尔出头。每个物体的外轮廓明显比内部结构线粗。
- **排线**：稀疏，暗处最多几道间距松散的短线，不要密集成簇或交叉排线，阴影主要靠平涂色和纯黑；物体脚下用三到五道短横线带出投影，不画地面。
- **色块**：每块颜色是一个均匀的平涂色调，边缘略软；上色松，有的地方没涂到线、有的地方涂出线外，露出细细的底色，像快速手工上色。亮面直接留底色。
- **两种底色**（同一张图只用一种）：
  - 白底：一到两个暖灰色调，除此以外没有颜色。
  - 浅棕底：灰蓝色（布与皮）、米白（骨）、最深处纯黑，除此以外没有颜色；可以加一个小草图和一条带箭头的潦草标注。
- **结构简单**：任何形体都要靠轮廓加几条内部线就能看懂，不设计需要大量细线才能表现的复杂结构（网格、层叠的膜、成簇的小刺、密集的破布或捆扎）。
- **细节均衡**：细节密度在整幅画里保持均匀，大块平涂里也带少量线条表现结构或皮肤、材质质感；不能某处很细、某处完全空白。

要避免：纹理、颗粒、笔触、积水痕、渐变、纸纹、色块里的斑驳污渍；线条过分干净均匀（矢量感）、满画面密集细节、塑料或金属高光、完美对称、边缘发光；署名和可读文字。
